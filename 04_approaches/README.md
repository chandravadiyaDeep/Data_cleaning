# 04 — Approaches

End-to-end decision strategies for selecting, combining, governing, and evaluating cleaning methods.

There is a matching approach folder for each of the 18 Knowledge Library categories. Each approach describes a workflow from context and profiling through detection, diagnosis, risk assessment, approval, execution, validation, and monitoring.

Use [the Knowledge Library category index](../01_knowledge_library/02_data_cleaning_categories/README.md) to navigate across knowledge, technique, and approach folders. Use `_templates/approach_note.md` for further research.
