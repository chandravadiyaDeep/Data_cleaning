Search-space concept

Two different trial counts.

The additive workload estimate and the category-combination search space describe different things. They should not be treated as interchangeable.

Additive treatment workload

Tadditive = 9 Σ ni

Nine alternative treatments per affected instance, when each instance is considered and tested independently. This is an application count, not the full configuration space.

Category-level combinations

Tcombination = 10k

One candidate code chosen for each of k categories. Instance-level combinations can grow much faster, so reduced-search methods may be needed.

Result comparison

Quality is more than error removal.

The research evaluates several dimensions together. No scores or preferred strategy are assumed before experiments.

Correction accuracyDid the treatment correct known errors?
Information preservationWas valid original information retained?
Data consistencyDo defined rules and relationships hold?
ML utilityDoes downstream task performance improve fairly?
Computational costWhat time, memory and trial effort were required?
Research guardrail

Every candidate trial must start from an unchanged copy of the original dataset. A strategy is not successful merely because it removes more flagged values. Valid information, statistical structure, downstream leakage and false corrections must also be examined.

The current GitHub Pages interface only selects a file locally and displays its name and size. It does not inspect, process, upload, store or transmit the dataset. The experimental engine will be designed separately.
