# Research Library — Stuff

This folder contains the research collections used to understand data cleaning before designing an implementation approach.

## Collections

| Folder | Purpose |
|---|---|
| [01_knowledge_library](01_knowledge_library/README.md) | Foundational concepts and data-cleaning categories. |
| [sectors](sectors/README.md) | 33 industry and domain knowledge profiles. |
| [02_technique_library](02_technique_library/README.md) | Technique catalogues for the 18 cleaning categories. |
| [03_experiment_library](03_experiment_library/README.md) | Reproducible experiments and evaluation records. |
| [04_approaches](04_approaches/README.md) | End-to-end approaches and decision strategies. |

## Research flow

**Sector and dataset context → Knowledge → Techniques → Experiments → Approach design → Implementation proposal**

Keep domain knowledge, individual techniques, measured evidence and end-to-end strategy separate. A technique should not become an automatic product rule until its assumptions, scope, validation evidence, false-positive risk and approval policy are understood.

The first practical software test page is maintained separately in the repository's [`site/`](../site/) directory.
